# Data-Structures

A collection of C++ implementations for fundamental data structures and algorithms.

## Description
This repository contains standalone C++ source files for common data structures such as BSTs, arrays, linked lists, queues, and stacks.

## Features
- binary search tree implementation
- array list implementation
- linked list implementation
- max heap implementation
- queue implementations
- stack implementations

## Technologies Used
- C++
- Standard library

## Prerequisites
- C++ compiler
- terminal or IDE

## Installation
```bash
g++ BST.cpp -o bst
g++ arrayList.cpp -o arraylist
```

## How to Run
```bash
./bst
./arraylist
```

## Project Structure
- `BST.cpp`
- `arrayList.cpp`
- `linkedLists.cpp`
- `maxHeap.cpp`
- `queueArray.cpp`
- `queueCircular.cpp`
- `queueLinkedList.cpp`
- `stackArray.cpp`
- `stackLinked.cpp`

## Notes
This repository is a collection of independent educational implementations rather than a single packaged application.
